# CV source

Run `python3 scripts/build-cv.py` from the repository root to rebuild
`files/seunghun-lee-cv.pdf`. Requires Python, PyYAML, and XeLaTeX.

Content comes from `_data/profile.yml` and `_publications/`.
Build files stay in ignored `.bundle/cv-build/`.

LPPL 1.3c in its original header. See the repository's `NOTICE.md`.
